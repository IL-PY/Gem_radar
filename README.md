# 🎯 GemRadar // Тактичний Радар Повітряного Простору

**GemRadar** — система моніторингу та візуалізації повітряних загроз у реальному часі (балістичні ракети «Іскандер-М/Кинджал», крилаті ракети «Калібр/Х-101», БПЛА «Shahed-136/Герань-2», КАБ) над Україною.

На відміну від статичних сервісів (*neptun, radar.ua*), GemRadar розраховує кінематичні моделі польоту, будує **неонові балістичні дуги** та плавно переміщує цілі по карті на **60 FPS** у реальному часі з підрахунком таймера підльоту (ETA).

---

## ⚡ Швидкий запуск (1 клік)

Просто запустіть файл у корені проєкту:
```bash
start_radar.bat
```
Він автоматично запустить сервер **FastAPI**, інтерфейс **Vite React** та відкриє радар у вашому браузері: `http://localhost:5173`.

---

## 🛡️ Безпека Telegram та захист від блокування (Anti-Ban)

Парсер розроблено з максимально делікатним протоколом взаємодії через офіційний MTProto-клієнт **Telethon**:

1. **Тільки пасивне прослуховування (Read-Only):**
   - Софт **не відправляє** жодних повідомлень, реакцій чи запитів на приєднання до каналів.
   - Використовується нативний потік оновлень `events.NewMessage()` без опитування (polling) у циклах.
2. **Емуляція офіційного клієнта:**
   - Клієнт маскується під офіційний додаток Telegram Desktop:
     - `device_model`: `PC 64bit`
     - `system_version`: `Windows 11 Pro`
     - `app_version`: `4.16.8 x64`
     - `lang_code`: `uk-UA`
3. **Відсутність масового скрапінгу історії:**
   - При запуску софт **не завантажує** тисячі старих повідомлень (що найчастіше викликає підозру сервера), а лише підписується на нові сповіщення.
4. **FloodSleep обробник:**
   - Автоматичний сон при будь-яких лімітах швидкості.

## 🔑 Підключення власної .session та API

1. Скопіюйте ваш файл сесії у папку `backend/` з назвою:
   ```
   backend/radar_session.session
   ```
2. Створіть або відредагуйте файл `backend/.env` (шаблон знаходиться у `backend/.env.example`):
   ```env
   TG_API_ID=ВАШ_API_ID
   TG_API_HASH=ВАШ_API_HASH
   TG_SESSION_FILE=radar_session.session
   ```
3. При наступному запуску GemRadar автоматично авторизується та перейде в режим онлайн-моніторингу!

> 💡 *Якщо сесію не вказано, GemRadar автоматично працює в режимі симулятора для безпечного тестування та демонстрацій.*

## 🚀 Як влаштована фізика траєкторій (Dead-Reckoning)

1. **Баллистика (Іскандер-М / Кинджал):**
   - Швидкість: ~7200 км/год (Mach 6).
   - Будується параболічна суборбітальна дуга (Bézier arc) від пускового району (наприклад, Брянська обл., Клинці) до цільового сектора (Вишгород / Київ).
   - На точці пуску розміщуються іконки СПУ (самохідних пускових установок).
   - Ракета летить плавно по дузі з живим зворотним відліком підльоту (ETA).
2. **Шахеди (Shahed-136):**
   - Швидкість: ~175 км/год.
   - Рух вздовж векторних коридорів із плавною інтерполяцією курсу при надходженні нових повідомлень.
3. **Крилаті ракети (Калібр / Х-101):**
   - Швидкість: ~820 км/год.
4. **Dead-Reckoning 60 FPS на клієнті:**
   - Позиція обчислюється щокадрово через `requestAnimationFrame`, забезпечуючи плавність польоту без ривків навіть при повільному інтернеті.

## 📱 Мобільний додаток (PWA / Android APK)

1. **Веб-версія на телефоні (PWA):**
   - Сайт повністю адаптовано під мобільні екрани з жестами карти та тач-панелями.
   - Можна додати на головний екран смартфона через меню браузера *"Додати на головний екран"*.
2. **Упаковка в Android APK (Capacitor):**
   ```bash
   cd frontend
   npm install @capacitor/core @capacitor/cli @capacitor/android
   npx cap init GemRadar com.gemradar.app
   npx cap add android
   npx cap run android
   ```

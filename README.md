# 🎯 GemRadar — радар повітряних загроз у реальному часі

**GemRadar** збирає повідомлення з Telegram-каналів моніторингу + live-стрічку [NEPTUN](https://neptun.in.ua/), розпізнає тип загрози (балістика, Shahed-136, реактивний Shahed-238, крилаті ракети, КАБ), будує траєкторію польоту і показує все на 3D-карті з таймером підльоту (ETA).

*Нижче — російською, далі — українською / Ниже — по-русски, далее — українською.*

---

# 🇷🇺 РУССКИЙ

## ⚡ Быстрый запуск (Windows, 1 клик)

1. Установи **Python 3.11+** (https://www.python.org/downloads/, при установке поставь галочку **Add to PATH**) и **Node.js LTS** (https://nodejs.org/).
2. Запусти **`start_radar.bat`** в корне проекта.
3. Браузер сам откроет `http://localhost:5173`.

Скрипт сам создаст виртуальное окружение, доставит зависимости, поднимет бэкенд (`:8000`) и фронт (`:5173`). Два чёрных окна «Backend» и «Frontend» во время работы **не закрывай**. Порты заняты? Скрипт сам прибьёт зависшие процессы на 8000/5173.

Без Telegram-сессии всё равно работает — в **режиме симулятора** (тестовые цели, кнопки в панели «Симулятор»).

## 🔧 Ручной запуск

**Бэкенд:**
```bash
cd backend
venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

**Фронт:**
```bash
cd frontend
npm install   # один раз
npm run dev -- --host --port 5173
```

## 📡 Подключение Telegram (live-мониторинг каналов)

1. Получи `API_ID` и `API_HASH` на https://my.telegram.org.
2. Скопируй `backend/.env.example` в `backend/.env` и впиши свои данные:
   ```env
   TG_API_ID=1234567
   TG_API_HASH=abcdef1234567890
   TG_SESSION_FILE=radar_session.session
   ```
3. Положи файл сессии Telethon (`radar_session.session`) в папку `backend/`.
4. Перезапусти бэкенд. Индикатор в шапке должен показать **TG ОНЛАЙН**.

Каналы по умолчанию (`kpszsu`, `vanek_nikolaev`, `war_monitor`, `air_alert_ua`, `eRadarrua`, `tryvoga_chomu`) меняются в `backend/app/config.py` → `MONITOR_CHANNELS`. Бот только **читает** — ничего не пишет, никуда не вступает, историю не скрапит (anti-ban).

> ⚠️ Файлы `.env` и `*.session` — твои личные данные, они **не попадают в git** (уже в `.gitignore`). Коммитить можно смело.

## 🖥️ Как пользоваться

- **Карта** — переключатель 2D/3D слева вверху (или кнопка в шапке). Мышь — панорама/зум, правая кнопка — наклон в 3D.
- **Шапка** — счётчики БАЛІСТИКА / ШАХЕДИ / КР-КАБ, живые часы, статусы сервера и TG.
- **Клик по цели** — карточка телеметрии: ETA, скорость, курс, пуск → цель, источник.
- **ЗВЕДЕННЯ ТГ** — лента последних сообщений из каналов.
- **СИМУЛЯТОР** — кнопки тестовых пусков (Искандер, Шахеды, Калибр, КАБ, Shahed-238), поле **«Спарсити»** для проверки парсера на своём тексте (напр. `Пуск шахеда з Курська на Київ`), кнопка очистки радара.
- **Легенда слева внизу** — тревоги по областям + live-статус NEPTUN.

## 📱 Android

### Вариант 1 — через браузер (1 минута, без установки)
1. Телефон и компьютер — **в одной Wi-Fi сети**.
2. Запусти радар на компьютере (`start_radar.bat`).
3. Узнай IP компьютера: `Win+R → cmd → ipconfig` → строка *IPv4-адрес* (напр. `192.168.88.17`).
4. На телефоне в браузере открой `http://192.168.88.17:5173` (свой IP).
5. Меню браузера → **«Добавить на главный экран»** — будет как отдельное приложение.

### Вариант 2 — отдельный APK
```bash
cd frontend
npm run build
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap init GemRadar com.gemradar.app
npx cap add android
npx cap run android        # или npx cap open android для Android Studio
```
> ⚠️ Для APK бэкенд должен быть доступен по сетевому адресу (внутри телефона `127.0.0.1` не подойдёт). Для работы через мобильный интернет нужен сервер/VPS или туннель (Cloudflare Tunnel, ngrok).

Интерфейс адаптирован под тач: карта жестовая, панели — на весь экран телефона.

## 🗂️ Структура

```
GemRadar/
├── start_radar.bat      # запуск в 1 клик (Windows)
├── run_backend.bat      # только бэкенд
├── run_frontend.bat     # только фронт
├── backend/
│   ├── .env.example         # шаблон настроек (свой .env не коммитить!)
│   └── app/
│       ├── main.py              # FastAPI: REST + WebSocket
│       ├── telegram_service.py  # MTProto-слушатель каналов
│       ├── parser.py            # разбор текстов тревог → цели
│       ├── geo_database.py      # города, районы пусков, гео-матчинг
│       ├── trajectory_engine.py # живые треки, корреляция сообщений
│       ├── neptun_threats.py    # live-треки NEPTUN
│       └── mock_simulator.py    # тестовые пуски
└── frontend/src/
    ├── App.tsx
    └── components/
        ├── TacticalMap.tsx  # карта + маркеры + траектории
        ├── Header.tsx       # шапка-хаб
        ├── TargetInspector.tsx / AlertsDrawer.tsx / SimulationControls.tsx
        └── threatIcons.ts   # иконки типов угроз
```

## ❓ Если что-то не работает

| Симптом | Что делать |
|---|---|
| Порт занят | `start_radar.bat` чистит сам; вручную: `netstat -ano \| findstr :8000`, `taskkill /F /PID <номер>` |
| `TG: СИМУЛЯТОР` вместо онлайна | Проверь `.env` и файл сессии в `backend/`, перезапусти бэкенд |
| `SESSION_UNAUTHORIZED` | Сессия протухла — перезапиши `.session` файл |
| Пустая карта, 0 треков | Это нормально без эфира; нажми «СИМУЛЯТОР» для проверки |
| Ошибки `npm` | Удали `frontend/node_modules`, выполни `npm install` заново |
